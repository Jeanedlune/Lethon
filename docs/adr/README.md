# Architecture Decision Records (ADR)

Index dan ringkasan keputusan arsitektur strategis untuk pengembangan **Lethon**.

| ID | Title | Status | Date | Decision Summary |
| :--- | :--- | :--- | :--- | :--- |
| [ADR-0001](0001-hybrid-spectral-rl-architecture.md) | 4-Stage Hybrid Spectral-RL Pipeline | Accepted | 2026-10-18 | Menggabungkan Fourier 1D, SAC, Subspace Masking, dan MDP CoT Pruning untuk kompresi hingga 66.7%. |
| [ADR-0002](0002-zero-proxy-mcp-integration.md) | Model Context Protocol (MCP) Over Proxy | Accepted | 2026-10-18 | Menggunakan standar MCP stdio/SSE dibanding proxy HTTP/SOCKS untuk zero-proxy distribution via `uvx`/`npx`. |
| [ADR-0003](0003-parameter-free-spectral-fft.md) | Parameter-Free 1D-FFT vs Heuristic Pruning for Stage 1 | Accepted | 2026-10-18 | Memilih 1D-FFT/DCT-II $\mathcal{O}(N \log N)$ dibanding Cosine Similarity & Attention Heuristics: latensi $< 3$ ms pada CPU, zero-parameter, tanpa torch berat. |
| [ADR-0004](0004-action-space-subspace-masking.md) | Dynamic Promising Token Subspace Masking (RLPT) for Policy Optimization Stability | Accepted | 2026-10-18 | Membatasi ruang aksi RL ke *low-rank subspace* prior semantik model dasar ($K = 4 \sim 8$) via logit-level masking ($-\infty$): reduksi varians gradien $\Delta V > 0$, eliminasi off-policy mismatch rollout vs backward pass, proteksi 100% token penalaran valid, dan peningkatan +3.6% akurasi Math-17k tanpa modul selektor eksternal. |
| [ADR-0005](0005-language-selection-python-to-rust.md) | Dual-Track Strategy (Python Research to Rust Core) | Accepted | 2026-10-18 | Python untuk validasi riset awal; porting ke single Rust binary saat siap rilis produksi. |
| [ADR-0006](0006-layer-aware-vs-uniform-spectral-filtering.md) | Layer-Aware vs Uniform Spectral Filtering for Transformer Sequences | Accepted | 2026-10-18 | Menetapkan Layer 1 sebagai split/compression point utama dengan polynomial scheduling $\rho(l)$ dan rekonstruksi simetri konjugat Hermitian: reduksi payload hingga 7.6x – 10.3x, akurasi terjaga $(< 0.3\%$ loss). |
| [ADR-0007](0007-semantic-anchor-vs-autoencoder-and-token-pruning.md) | Semantic Anchor (SAC) vs Rigid Autoencoders and Heuristic Pruning | Accepted | 2026-10-18 | Memilih in-context semantic anchors dengan bidirectional attention dan pelatihan autoencoding-free: eliminasi konflik ortogonalitas gradien $\mathcal{L}_{AE} \perp \mathcal{L}_{LM}$, preservasi manifold KV tanpa distribution shift, hemat 1.19x FLOPs, dan unggul hingga +23.5% F1 atas ICAE. |
| [ADR-0008](0008-dynamic-cot-pruning-vs-heuristic-budget-forcing.md) | Dynamic RL CoT Pruning (ThinkPrune) vs Heuristic Budget-Forcing and Static Text Truncation | Accepted | 2026-10-18 | Memilih optimasi RL dengan length clipping dan iterative schedule ($4k \to 3k \to 2k$) dibanding pemotongan paksa heuristik (s1/budget-forcing): mengeliminasi truncation blindness, memangkas 50%–65.5% token CoT dengan degradasi akurasi downstream hanya ~2% (AIME24), membalik kenaikan akurasi pada model belum tersaturasi (+0.6%), dan mempertahankan keterbacaan (PPL 1.90 vs 1.91). |
| [ADR-0009](0009-lfd-warm-start-and-performance-efficiency-reward.md) | Learning from Demonstrations (LfD) Warm-Start and PPO Performance-Efficiency Reward Optimization for Sequential Token Pruning | Accepted | 2026-10-18 | Memilih strategi dua fase: supervised LfD warm-start di atas trajektori demonstrasi heuristik bertahap dilanjutkan fine-tuning PPO multi-langkah ($T_{\max}=3$) dengan reward diferensial komposit $r_t = R_{\text{task}} + R_{\text{eff}}(t)$: mengatasi ledakan ruang aksi $2^{K_t}$, mencegah policy collapse (retensi VQAv2 99.6% vs 96.3% RL from scratch), memangkas 66.7% token, reduksi 54.2% FLOPs, dan memangkas 66.6% KV-cache dengan degradasi akurasi downstream hanya 0.7% (MMBench 102.3%). |
| [ADR-0010](0010-entropy-guided-regulation-and-semantic-curriculum.md) | Entropy-Guided Non-Uniform KL Regulation and Semantic Curriculum Learning (SENT) for LLM Reasoning Stability | Accepted | 2026-10-18 | Mengadopsi kerangka kerja dual-level SENT: kurikulum data berbasis Semantic Entropy ($N=2$) dan regulasi non-uniform KL divergence adaptif ($\beta_{\text{con}} \in \{0.0, 0.5, 2.0\}$) pada token berkovarians tinggi: mencegah entropy collapse dan explosion pada pemangkasan CoT, menaikkan Pass@32 AIME24 ke 76.67% (+33.3% vs GRPO), rata-rata 6 benchmark 68.57%, dan memperkuat penalaran reflektif/self-correction. |
| [ADR-0011](0011-multi-agent-markov-game-layer-pruning.md) | Multi-Agent Markov Game (MAPPO) vs Single-Agent and Heuristic Cross-Layer Pruning for KV-Cache Compression | Accepted | 2026-10-18 | Mengadopsi formulasi Markov Game CTDE via Multi-Agent PPO (MAPPO) dengan shared lightweight MLP actor dan centralized critic untuk pemangkasan token dan KV-Cache lintas layer: adaptif data penuh, prioritas eliminasi redundansi di layer awal (earliest-stage pruning), menghindari ledakan ruang aksi $2^N$, menghasilkan speedup inferensi hingga +44% dengan akurasi drop < 0.4%. |
