| [DEC-05](dec-05-tprl-token-compression-mdp.md) | Sequential Decision MDP & Autoencoder Compression (TPRL) | Stage 4 | arXiv:2603.13394v1 | Formulasi tuple MDP $(\mathcal{S}, \mathcal{A}, \mathcal{P}, \mathcal{R}, \gamma)$ language-guided untuk pemangkasan token visual/konteks sekuensial, representasi state ringkas via self-supervised token-wise autoencoder ($d_v \to d_l$, kompresi $16\times$), pelacak bitmask global $m \in \{0, 1\}^N$, modul atensi bersama (Shared MHSA), warm-start Learning from Demonstrations (LfD), eksplorasi Bernoulli terdiskon ($\lambda_{\text{disc}}^t$), dan optimasi reward komposit dual-kriteria PPO (retensi akurasi 99.3%, FLOPs -54.2%, KV-cache -66.6%). |
| [DEC-06](dec-06-entropy-collapse-curriculum-sent.md) | Entropy Collapse Prevention & Semantic Curriculum Learning (SENT) | Stage 4 | arXiv:2512.04359v3 | Formulasi Semantic Entropy ($H_{\text{SE}}$) berbasis klaster ekuivalensi semantik, kurikulum dua tahap data ($D_{\text{sorted}} = \text{sort}(D, \text{key}=H_{\text{SE}})$), analisis kovarians kepercayaan-advantage $\text{Cov}_t$, regulasi non-uniform KL divergence adaptif ($\beta_{\text{con}} \in \{0.0, 0.5, 2.0\}$), dan mitigasi entropy collapse pada pemadatan Chain-of-Thought (AIME24 Pass@32 76.67%, rata-rata 6 benchmark 68.57%). |
| [DEC-07](dec-07-markov-game-mappo-pruning.md) | Markov Game Token Pruning & Multi-Agent PPO (MAPPO) Cross-Stage Optimization | Cross-Stage | arXiv:2503.23459 | Formulasi Markov Game token pruning multi-layer dengan desentralisasi eksekusi CTDE via Multi-Agent PPO (MAPPO), parameter-shared actor & centralized critic ($s_{\text{local}} \| s_{\text{global}}$), fungsi reward ganda kompetitif-kolaboratif ($r_{1,i}^l = -A_i^l$, $r_{2,i}^l = \gamma / n_l$), GAE advantage estimation, pemangkasan non-destruktif berbasis attention masking (-1000.0), dan optimasi KV-cache layer awal (+44% inference speedup, akurasi drop < 0.4%). |
