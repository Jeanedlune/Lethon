# Design Engineering Concepts (DEC)

Index dokumentasi teknis, landasan matematis, dan spesifikasi arsitektur modul untuk **Lethon Engine**.

| Dokumen | Nama Modul | Tahap Pipeline | Paper Acuan Utama | Deskripsi Teknis Singkat |
| :--- | :--- | :--- | :--- | :--- |
| [DEC-01](dec-01-spectral-filtering-math.md) | Fast Spectral Fourier Filtering & Layer-Aware Activation Compression | Stage 1 | arXiv:2508.06038, arXiv:2510.16418 | Formulasi 1D/2D FFT/DCT-II ortonormal $\mathcal{O}(N \log N)$, analisis kehalusan & konsentrasi energi spektral layer awal transformer, rekonstruksi simetri konjugat Hermitian, scheduling layer-aware, serta implementasi NumPy/SciPy (< 3ms CPU). |
| [DEC-02](dec-02-semantic-anchor-aggregation.md) | Contextual Semantic Anchor Aggregation (SAC) | Stage 2 | arXiv:2510.08907 (ICLR 2026) | Kompresi konteks autoencoding-free via in-context anchors, injeksi learnable anchor embedding $e_A$, atensi dua arah penuh (bidirectional cross-attention), penyerapan Key-Value representations multi-layer, preservasi manifold topologi t-SNE, dan eliminasi sequence padding FLOPs ($5\times - 51\times$). |
| [DEC-03](dec-03-rlpt-promising-token-masking.md) | Dynamic Promising Token Subspace Masking (RLPT) | Stage 3 | arXiv:2602.03195v2, arXiv:2512.04359 | Isolasi ruang aksi RL ke dalam *low-rank subspace* dari prior semantik model dasar, formulasi matriks masking dinamis $M_t \in \{0, 1\}^{|\mathcal{V}|}$, logit masking deterministik ($-\infty$), pembuktian analitik reduksi varians gradien $\Delta V > 0$ (Proposition 4.1), thresholding adaptif (Top-K, Top-P, Min-P, Subspace SVD), eliminasi off-policy mismatch pada GRPO/DAPO, dan stabilisasi konvergensi penalaran (+3.6% Math-17k). |
| [DEC-04](dec-04-cot-iterative-pruning.md) | Sequential Decision MDP & CoT Length Truncation | Stage 4 | arXiv:2504.01296, arXiv:2603.13394 | Formulasi MDP & GRPO untuk pemangkasan alur pikir penalaran panjang (*Chain-of-Thought*) berulang pada model DeepSeek-R1/o1/QwQ, evaluasi reward berbasis strict length clipping $R_{\text{clip}}(Y; L)$, kurikulum iterative pruning schedule ($4k \to 3k \to 2k$) dengan toleransi validasi AIME22/23 ($\le 10\%$), taksonomi thought redundancy (penurunan 70% frase keraguan, pergeseran budget ke komputasi inti 31.6%), preservasi perplexity (1.90 vs 1.91), dan reduksi 63.6% token AIME24 dengan retensi akurasi downstream (drop hanya ~2%). |
